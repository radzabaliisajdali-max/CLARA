CLARA V4 — FBS-конвейер

Добавлено:
- Новые заказы / Лист подбора / Сборка поставки / Управление поставками
- Скан GTIN или баркода товара
- Автоматический выбор подходящего FBS-заказа
- Автозапуск печати стикера после сканирования
- Стикер 58×40 мм
- Скан стикера → автоматический переход к КИЗ
- Скан КИЗ → привязка к заказу → статус «Готов к отгрузке»
- Проверка повторного использования КИЗ
- Контур Local Print Agent: http://127.0.0.1:17890

Важно: для реальной тихой печати без диалога браузера нужен локальный Print Agent. Сейчас при отсутствии агента CLARA использует резервную печать браузера. Реальные WB-заказы и официальный стикер будут подключены через серверный WB API на следующем этапе.
