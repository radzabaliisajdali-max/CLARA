# CLARA V4.1 — рабочая базовая сборка

## Что зафиксировано
- Все основные разделы открываются через единый роутер `show()`.
- Ошибка одного раздела больше не должна превращать приложение в пустой экран: показывается техническая ошибка и кнопка возврата.
- Товары: поиск, карточка, создание/редактирование, сохранение, CSV.
- Производство: количества по каждому размеру, автоматический итог, приход на внутренний склад, история партий.
- Склад: остатки и просмотр по размерам.
- FBS: новые заказы, лист подбора, сборка, управление поставкой, цепочка товар → стикер → КИЗ → готово.
- Подготовлен контур автоматической печати через Local Print Agent.
- Честный ЗНАК: локальный журнал КИЗ и контроль повторного использования.
- Аналитика: рабочее переключение подразделов, WB/Ozon, фильтр заказов, метрики, экспорт.
- Настройки: вкладки теперь действительно переключаются.
- Настройки расчётов сохраняются в localStorage.
- Добавлен журнал изменений.

## Важное по FBS-стикеру
По актуальной инструкции Wildberries физический размер стикера заказа указан как **40×58 мм**. В CLARA это отображается как 40×58 мм с ориентацией 58×40, чтобы не путать физический размер с ориентацией печати.

## Что пока НЕ выдаём за готовое
- Реальный WB API ещё не подключён.
- Реальный API «Честного ЗНАКА» ещё не подключён.
- Настоящий WB стикер должен приходить из WB API; локальный прототип не должен подменять его выдуманным кодом.
- Для бесдиалоговой печати нужен Local Print Agent на рабочем ПК.
