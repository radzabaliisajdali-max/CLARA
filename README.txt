CLARA V1
1. Загрузить ВСЕ файлы из этого архива в GitHub -> репозиторий CLARA.
2. В Render выбрать New Static Site.
3. Выбрать репозиторий CLARA.
4. Build Command оставить пустым.
5. Publish Directory поставить .
6. Нажать Deploy.
WB API подключается позже на серверной части. Секретный токен WB не помещать в браузерный код.
