# Реклама WB: подключение чтения

В меню «Аналитика и рост → Реклама WB» реализованы список кампаний и статистика за выбранные даты. Для нового интерфейса список кампаний загружается отдельной кнопкой, затем отмечаются кампании и запрашивается отчёт.

1. Создайте в своём кабинете WB токен категории «Продвижение» только для чтения.
2. Вставьте его локально в серверный `.env` как `WB_ADS_TOKEN=...`. Не присылайте его в чат и не включайте `.env` в Git.
3. Пересоздайте приложение: `docker compose up -d --force-recreate app`.
4. Откройте «Реклама WB» и нажмите «Загрузить кампании». Статус «Токен задан» не означает проверенный доступ: его подтверждает успешный ответ WB.

Адаптер обращается только GET к `/adv/v1/promotion/count` и `/adv/v3/fullstats` на `advert-api.wildberries.ru`. Изменение ставок, бюджета, запуск или остановка кампаний не реализованы. Статистика: максимум 50 выбранных кампаний, период до 31 дня. Поддерживаемые статусы отчёта: 7, 9, 11.

Снимки сохраняются в PostgreSQL и резервной копии. Свежий ответ повторно используется минуту, лимит запросов координируется в БД между процессами. После ошибки возвращается прежний отчёт с пометкой устаревания; при отсутствии снимка — понятная ошибка. Токен не возвращается в API и не сохраняется в снимках. Текущий вариант рассчитан на один кабинет WB; смена токена отделяет кэш.

CTR/CPC/ДРР показываются только при наличии исходных значений и положительного знаменателя. ДРР здесь считается от суммы заказов, атрибутированных рекламе WB. Это не фактическая прибыль и не доказанный прирост продаж.

Маршруты CLARA:
- GET /api/v1/integrations — конфигурация модулей без секретов;
- GET /api/v1/wb/ads/campaigns — список и время получения;
- GET /api/v1/wb/ads/statistics?ids=123,456&beginDate=2026-10-01&endDate=2026-10-05 — отчёт.

Локальные тесты используют контролируемые ответы WB: успех, кэш, неверный период, ограничение частоты и отказ доступа. Живое подключение пользовательского кабинета не проверено: токен не задан. Остальные WB-интеграции пока обозначены как неподключённые.

Официальный источник: https://dev.wildberries.ru/en/docs/openapi/promotion?locale=ru%2F .
